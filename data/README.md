# Employee Salary Prediction

## 📌 Project Overview
This project predicts an employee's salary based on factors such as age, education level, and years of experience using Machine Learning in Python.

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
